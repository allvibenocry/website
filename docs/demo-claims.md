# The demo's claims

Everything the control panel's demo, [site/demo.html](../site/demo.html) at
`/demo`, shows about the product, with its source in the product repository and
its status (D27). The demo is the owner's reference design for the panel
(product [DECISIONS.md, D51](https://github.com/allvibenocry/allvibenocry/blob/6a20da84c80ee4499a1073b83c5eda86698f3da8/DECISIONS.md#d51-the-control-panels-design-the-owners-demo-and-its-rules)), with pretend data and a scripted AI, and it
says so in its yellow banner. This file says, screen by screen, what in the
product each thing it shows rests on.

**Read at:** [allvibenocry/allvibenocry](https://github.com/allvibenocry/allvibenocry/tree/6a20da84c80ee4499a1073b83c5eda86698f3da8) commit `6a20da8`,
2026-09-28, the product's fourth brief. Source links point into that commit.

**Statuses:**

- **Built**: the product does this today, in its command-line tool, built and
  tested on the local test host; not yet on real hardware, and not yet tried
  by the owner. **The panel itself is Planned**
  ([roadmap: the control panel at allvibe.local](https://github.com/allvibenocry/allvibenocry/blob/6a20da84c80ee4499a1073b83c5eda86698f3da8/docs/roadmap.md#the-control-panel-at-allvibelocal)), so a Built row
  means the thing behind the screen exists, never the screen.
- **Planned**: an entry of the product's roadmap or a decision. Nothing of it
  is built.
- **No source**: nothing in the product says this, or the product says less.
  Each one is listed again at the end, for the owner. The demo keeps its words,
  as the brief asks; this file does not.

Pretend data (names, counts, sizes, times, commit ids and the like) is the
demo's own and is not listed, except where it stands for something the product
decides.

## Without a source, for the owner

What the demo shows that nothing in the product says, or that goes further than
the product. The demo keeps its words, as the brief asks. Each needs a
decision in the product, or a change to the demo:

1. **"Tried by you" as a safety check before a release** (DA9; also DA2, DF1 and
   DN1: "you try every step before anything goes live"). The guided plan asks
   the agent to stop after each step for the person to try it, but a release
   does not know whether anyone did.
2. **A fresh backup, checked, before going back** (DV4). The product's rollback
   changes only the code and keeps the data, and takes no backup; only
   `--restore-data`, which puts data back, takes one first.
3. **Checks every night** (DM1). The nightly run is the backup and its restore
   check; doctor's checks run when asked, and the check-up is planned monthly.
4. **Power and battery** (DM6). Nothing reads them.
5. **`allvibe-guestbook-gate`** (DM10). The product calls it
   `allvibe-guestbook-agent-egress`.
6. **Services reachable only from the home network** (DS7). The roadmap entry
   does not say who can reach a service.
7. **The bridge's `/allvibe` command, its address on port 8700, and a
   one-time connection code valid for 10 minutes** (DT4, DT5). None of this is
   decided.
